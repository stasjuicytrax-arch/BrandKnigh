# BrandKnight: инструкция для Claude Code

Это проект редизайна brandknight.ru. Сейчас закончен этап подготовки, следующий этап — вёрстка.

Читать в таком порядке:
1. `TZ.md` — что делать и в каком порядке (раздел 9 — план по этапам).
2. `DESIGN.md` — как это должно выглядеть. Главный документ по внешнему виду.
3. `PRODUCT.md` — для кого и зачем.
4. `content/` — тексты, кейсы, манифест ассетов.
5. `.impeccable/surfaces/index-html.md` — контракт направления (не копировать в код сайта).
6. `.taste-skill/direction.json` — раздача taste-skill (`node <taste-skill>/scripts/draw.mjs --show`).

**ВАЖНО (26.10.2026):** стиль пересобран. DESIGN.md v2 «Стекло и свет» заменяет «Хромового рыцаря». Эталон — `design/concept/index.html` (утверждён заказчиком). Хромовые буквы BRK, белый пустой фон и стена из афиш отклонены. Правила Taste Skill о запрете стекла/градиентов/теней/карточек/пилюль на этом проекте НЕ действуют (см. DESIGN.md §10).

Правила:
- **Контрольная точка:** после первых трёх экранов (TZ.md §9, этап 3½) остановиться, показать заказчику и спросить, нравится ли стиль. Без ответа «идём дальше» не продолжать.
- После каждого законченного блока: `/impeccable critique`, правки, запись в `NOTES.md`, коммит и `git push` (заказчик следит за репозиторием).
- Перед финальным пушем: `impeccable detect` (slop) → `/impeccable polish` → `/impeccable audit`, taste `inspect.mjs` без FAIL.
- Ничего не выдумывать: цены, сроки, отзывы, цифры, клиентов. Если чего-то нет, спросить заказчика.
- Только русский язык в интерфейсе.
