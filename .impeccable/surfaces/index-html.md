# Surface: главная страница brandknight (index)

Scope: одностраничный сайт-портфолио студии + /policy. Mode: **Experience/Persuade** (портфолио: впечатление и работы ведут, заявка — следствие).
Audience: ивент-индустрия и бизнес; приходят из рекламы, часто с телефона.
Constraints: Unbounded + Onest, без цен, русский (слоган WE CREATE DIGITAL SOLUTION — исключение), GitHub Pages, обязательные 21st.dev компоненты, Three.js.

## Direction contract (v2, утверждено 26.10.2026 по живому образцу design/concept/index.html)
THESIS: Студия показывает вкус, а не продаёт: стеклянный 3D-узел проходит сквозь слоган, интерфейс из стекла и света, работы — экспонаты в бенто и врезках. Отказ от «белого фона с чёрными буквами» и от стены афиш.
OWN-WORLD: Светлая сцена #F3F5EF с дрейфующими лаймовыми и мятными пятнами и зерном; жидкое стекло с радужным переливом; матовые стеклянные панели, пилюли, круглые кнопки ↗, вращающийся лаймовый бейдж; бенто скруглённых плиток (одна лаймовая, одна тёмная); Unbounded 800 капс.
STORY: Посетитель видит красивую живую сцену, понимает «это студия с вкусом», смотрит видео-креативы и сайты в бенто, пишет в Telegram.
FIRST VIEWPORT: Сцена-карта 40px радиус; по центру «WE CREATE / DIGITAL / _SOLUTION», сквозь которые проходит стеклянный узел; стеклянная навигация сверху; вертикальная панель слева; счётчики справа; бейдж «НАПИШИ НАМ»; слева внизу стеклянная карточка с дополнением и кнопками; справа внизу карточка с играющим роликом MEG.
