# Product

## Platform

web

## Stack

Решено с заказчиком: статический сайт на GitHub Pages (деплой из репозитория `stasjuicytrax-arch/BrandKnigh`).
Делегировано: Vite + React 18 + TypeScript + Tailwind CSS, Three.js через @react-three/fiber и @react-three/drei, GSAP + ScrollTrigger, Lenis (плавный скролл), framer-motion (нужен компонентам 21st.dev). Причина: компоненты 21st.dev, которые заказчик сделал обязательными, написаны на React + Tailwind; GitHub Pages требует статической сборки.

## Users

1. Ивент-индустрия: диджеи, промоутеры, клубы, бары, караоке, организаторы вечеринок и фестивалей. Им нужны анимированные афиши и сторис к каждому событию, быстро и регулярно (поток, а не разовый заказ).
2. Артисты и ведущие (диджеи, дуэты, ведущие мероприятий), которым нужен сайт или пресс-кит для букинга.
3. Малый и средний бизнес и стартапы: нужен сайт, логотип, креативы для рекламы, бренд-персонаж.

Приходят в основном из платной рекламы, часто с телефона. Решают за секунды: «эти ребята умеют делать красиво, хочу так же».

## Product Purpose

BrandKnight — студия цифрового дизайна (Россия). **Сайт — портфолио** (уточнение заказчика 26.10.2026): он должен выглядеть «охуительно», впечатлять с первого экрана и показывать работы. Заявка в Telegram — следствие впечатления. Успех: человек говорит «вау», смотрит работы и пишет.

## Positioning

Студия, которая сама живёт внутри ивент-индустрии: делает афиши и видео-креативы для реальных клубных вечеринок и пресс-киты реальных диджеев (DJ NAGOO, OPPAACHA, LOLLY, 39 KINGDOM), сайты караоке-лофтов и ивент-агентств. Портфолио здесь — это постеры и сайты настоящих событий, а не концепты.

## Operating Context

Основные источники дохода, по словам заказчика: (1) анимация афиш / рекламные видео-креативы, (2) создание сайтов. Им отдаётся главное место на странице.
Прочие направления, сохраняемые со старого сайта: статичные креативы (афиши, сторис), логотипы, бренд-персонажи, клиенты/партнёры, контакты.

## Capabilities and Constraints

- Только русский язык.
- Цены и прайс на сайте НЕ публикуются.
- Форма заявки отправляет данные в Telegram (как сейчас на старом сайте). Механика старого сайта — Tilda-форма с отправкой в Telegram; на новом сайте нужен эквивалент (см. TZ.md, раздел «Форма»).
- Кнопка «Скачать презентацию» не нужна.
- Хостинг: GitHub Pages.
- Светлая основа со светом и стеклом (DESIGN.md v2). Не «белый фон с чёрными буквами»: каждый экран насыщенный, как в референсах.

## Brand Commitments

- Название: BrandKnight (в логотипе — BRK). Логотип оставляем старый.
- Цветовая основа задана заказчиком: белый, чёрный, кислотно-салатовый (из референсов в `references/`).
- Обязательные элементы: 3D на Three.js («дорогие фишки»; хромовые буквы BRK отклонены, стена из афиш на первом экране отклонена), кнопка Apple Tahoe Liquid Glass (21st.dev, @jahed), а также Tilted Grid Hero (@ruixen.ui) и Circular Carousel (@nexus-ui).
- Тон: ультрасовременный, модный, много анимации, вау-эффект с первого экрана.
- Instagram: @brandknight.design, @stastoropov.

- Нет цифр (кол-во клиентов, лет на рынке). Не выдумывать; если нужны счётчики, заказчик даёт цифры.

## Product Principles

1. Работа показывает себя сама: афиши и сайты крупно, в движении, с первого экрана.
2. Два главных продукта (афиши-анимация и сайты) получают самые сильные сцены страницы.
3. Каждый экран ведёт к заявке, путь до Telegram — один тап.
4. Вау-эффект не мешает телефону: 60 fps на среднем смартфоне, фолбэки без WebGL.
