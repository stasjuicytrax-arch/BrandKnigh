Версия 1.0 · 25.10.2026 · Исполнитель вёрстки: Claude Code в терминале на компьютере заказчика.

Перед началом прочитать: `PRODUCT.md` (кто и зачем), `DESIGN.md` (как выглядит), `content/old-site.md` (тексты), `content/cases.md` (кейсы), `references/README.md` (референсы).

## 0. Коротко

- **Что:** одностраничный сайт студии BrandKnight + страница `/policy`.
- **Главная цель:** заявка в Telegram от человека из рекламы.
- **Главные продукты** (им лучшие сцены): ① анимация афиш / видео-креативы, ② создание сайтов.
- **Мир:** «Хромовый рыцарь». Светлый фон, чёрный текст, кислотный лайм, жидкий хром в 3D, жидкое стекло, огромная узкая капитель.
- **Язык:** только русский. **Цен нет.** **Кнопки «Скачать презентацию» нет.**
- **Хостинг:** GitHub Pages, репозиторий `stasjuicytrax-arch/BrandKnigh`.

## 2. Подготовка материалов (первый шаг в терминале)

1. `node scripts/download-assets.mjs` скачивает 126 файлов старого сайта по `content/assets-manifest.json` в `public/assets/old-site/`. Потом глазами проверить: пары «обложка ↔ YouTube» (группа `videos`) и «скриншот ↔ сайт» (группа `sites`); подписи на иконках услуг; названия клиентов по логотипам. Результаты записать в `src/data/*.ts`.
2. **Видео-креативы:** установить `yt-dlp` и `ffmpeg` и скачать 23 уникальных ролика из манифеста. Для каждого сделать:
   - `loop.mp4`: 540×960, без звука, H.264, `-crf 28 -preset veryfast -movflags +faststart`, первые 6–8 с (для превью в карточках и окне-в-строке);
   - `full.mp4`: 720×1280, со звуком AAC 128k, `-crf 24 -preset veryfast -movflags +faststart` (для лайтбокса);
   - `poster.webp`: кадр с 1-й секунды, 540×960.
   Если исходник горизонтальный, не обрезать: сделать 16:9-карточку (в данных поле `ratio`).
   Сложить в `public/assets/videos/<id>/`. Каждый файл должен быть меньше 25 МБ.
3. **Dropbox mp4** (5 шт.) скачиваются тем же скриптом. Сторис `video-5.mp4` и `video-story-3.mp4` перекодировать так же.
4. **Скриншоты новых кейсов:** Playwright снимает 7 новых сайтов из `content/cases.md` в 1440×900 и 390×844, плюс полноразмерный скрин (fullPage) для «прокрутки внутри устройства». Формат WebP, качество 82.
5. **Логотип:** `BRK_White.svg` и `_1.svg`/`_4_1.svg` — посмотреть, какой из них знак рыцаря/BRK. Подготовить чистый SVG-путь знака для экструзии в 3D (`src/three/knight-path.svg`): один цвет, без растровых вставок, замкнутые контуры.
6. **Текст политики** со страницы https://brandknight.ru/policy перенести в `src/data/policy.ts`.
7. **Telegram заказчика:** `src/data/site.ts → telegram`. ⚠️ Если username ещё не записан в этом файле, спросить у заказчика до вёрстки формы.

## 3. Сквозные элементы

### 3.1 Прелоадер (только первый визит, `sessionStorage`)
Белый экран. В центре 6–8 капель жидкого хрома (MarchingCubes из `three/examples/jsm/objects/MarchingCubes`) сливаются в одну, и из неё проявляется знак BRK. Внизу счётчик `0–100` (Small, tabular-nums). Длительность ограничена загрузкой, но не меньше 900 мс и не больше 2000 мс. Затем шторка: экран прелоадера уезжает вверх clip-path'ом (800 мс), под ним уже первый экран, где тот же рыцарь в той же позиции (бесшовный переход).
На телефоне и при reduced motion капель нет: знак BRK проявляется opacity за 400 мс.

### 3.2 Шапка
- Десктоп: слева место логотипа (на первом экране пустое: туда прилетит 3D-рыцарь, см. 4.1). Ссылки: **Афиши · Сайты · Услуги · Клиенты · Контакты**. Справа кнопка `glass-lime` **«Написать в Telegram ↗»**.
- После 100vh шапка становится стеклянной полосой `glass-clear`. При скролле вниз прячется, при скролле вверх появляется.
- Телефон: логотип, кнопка «Меню». Полноэкранное меню на лаймовом поле, пункты размером Head, снизу кнопка Telegram и Instagram. Открытие: поле выезжает сверху clip-path, пункты появляются с задержкой 50 мс.

### 3.3 Курсор (только `pointer: fine`)
Точка 10px `ink`, mix-blend нет. Над медиа превращается в лаймовый круг 88px с текстом «Смотреть» (видео), «Зажми» (афиша в сцене 4.3), «Открыть» (кейс). Над ссылками 40px. Пружина: stiffness 300, damping 30.

### 3.4 Плавный скролл
Lenis (lerp 0.1) только на десктопе, синхронизирован с ScrollTrigger. Якорные ссылки скроллят через Lenis со смещением под шапку.

### 3.5 Главная кнопка
Компонент `LiquidGlassButton` (21st.dev @jahed, код даст заказчик). Пресеты `glass-lime` и `glass-clear` из DESIGN.md §6. Текст всегда про действие: «Написать в Telegram», «Заказать анимацию», «Обсудить сайт». Клик ведёт в Telegram (см. 4.12) и отправляет цель Метрики `tg_click` с параметром `place`.

## 4. Страница: секции по порядку

Каждый заголовок проверен на правило «≤ 2 строк, ≤ 14 знаков капсом на строку на 390px».
H1 один, в первом экране. У каждой секции есть `<h2>` и `id` для меню.

### 4.1 Первый экран: «Хромовый рыцарь» `#top`

**Композиция** (taste: «Title in the sky, line on the horizon»):
- Вся высота 100svh, фон `ground`.
- **Верхняя зона:** заголовок Display в две строки, по центру.
  `ДВИЖЕНИЕ [окно] / ПРОДАЁТ`
  В первой строке после слова стоит **окно-в-строке** (DESIGN.md §9) с живой анимированной афишей (`loop.mp4`). Афиши в окне меняются каждые 3 с, переход «шторкой» снизу вверх.
  Для поисковиков и скринридеров в h1 скрыто добавлено: «BrandKnight — анимация афиш и создание сайтов».
- **Нижние 55%:** 3D-сцена, хромовый рыцарь (знак BRK, экструзия, хром). Объект ~38vw на десктопе, ~70vw на телефоне.
- **Линия горизонта** (52% высоты): поясняющая фраза Lead разрезана на две половины, рыцарь виден в просвете между ними:
  слева, выровнено вправо до колонки 5: «Студия BrandKnight анимирует афиши»
  справа, от колонки 8: «и делает сайты, которые собирают заявки.»
- Под рыцарем по центру кнопка `glass-lime` **«Написать в Telegram ↗»** (стекло преломляет хром за собой), рядом текстовая ссылка «Смотреть работы ↓» (→ 4.3).
- Телефон: заголовок 2 строки по 11vw сверху (96px от края), фраза двумя строками по центру под ним, рыцарь в нижней половине, кнопка во всю ширину в 24px от низа.

**3D-сцена `KnightScene`:**
- Геометрия: `SVGLoader` → `ExtrudeGeometry` (depth 0.35, bevelEnabled, bevelSize 0.04, bevelSegments 8 на десктопе / 3 на телефоне), центрирование, нормали сглажены.
- Материал: `MeshPhysicalMaterial` metalness 1, roughness 0.06, clearcoat 1, clearcoatRoughness 0.05. Вариант «жидкости»: в вершинном шейдере (onBeforeCompile) слабое смещение по simplex-noise (амплитуда 0.015, медленно), чтобы металл «дышал».
- Окружение: `Environment` с Lightformer-панелями (2 белые прямоугольные сверху и слева, 1 лаймовая узкая полоса справа, 1 чёрная снизу). Лаймовая полоса каждые 6 с проезжает по дуге, и по металлу бежит лаймовый блик.
- Поведение: медленный дрейф-вращение (Y ±12°, период 8 с), наклон к курсору (±15°, пружина), на телефоне наклон от гироскопа (DeviceOrientation, только после жеста; без разрешения не спрашивать, просто дрейф).
- Под объектом мягкая контактная тень (`ContactShadows`, opacity 0.25). Это единственная тень на сцене.
- **Фирменное движение «Полёт»:** ScrollTrigger на 0→100vh первого экрана (scrub 0.6). Рыцарь уменьшается, поворачивается на 360° по Y и перелетает в место логотипа в шапке (экранные координаты считать через `getBoundingClientRect` пустого слота логотипа). В конце канвас прячется, в слоте появляется SVG-логотип (подмена на последнем кадре, без скачка). При скролле назад всё идёт в обратную сторону.
- Канвас: `dpr={[1, 1.75]}` (телефон `[1, 1.5]`), `frameloop="demand"` вне вьюпорта, `PerformanceMonitor` из drei понижает DPR при падении FPS.
- Фолбэк: нет WebGL или reduced motion → `public/assets/fallback/hero.webp` (рендер сцены, снять скриншотом канваса после вёрстки).

**Анимация входа** (после прелоадера): строки заголовка выезжают из-под маски (900 мс, stagger 120 мс), окно-в-строке открывается шторкой, половины фразы съезжаются от центра (600 мс), кнопка появляется последней.

### 4.2 «Привет» `#hello` (бегущая строка со старого сайта)
Одна строка Head-размера на всю ширину, бесконечная: «ПРИВЕТ // HALLO // BUENOS DÍAS // GUTEN TAG // OLÁ // MERHABA // 你好 // HYVÄÄ PÄIVÄÄ // SZERVUSZ // ΓΕΙΆ ΣΑΣ // BONJOUR //». Вместо «//» стоит маленький хромовый знак BRK (статичная PNG-картинка рендера, 0.6em). Скорость и наклон skewX ±8° зависят от скорости скролла (Lenis velocity). Под строкой одна фраза Lead со старого сайта, слева в колонках 1–7: «Мы внимательны, дружелюбны и просты. Работаем со стартапами, бизнесом и ивент-индустрией.»
Заголовок секции: h2 «Привет» (визуально скрыт, сама строка и есть заголовок; `aria-hidden` на дублях строки).

### 4.3 Сцена «Статику листают — движение смотрят» `#afishi` (главный продукт №1)
**Композиция** (taste: «One frame, three distances», пиннинг):
- Обёртка 300vh на десктопе и 200vh на телефоне, внутри липкая сцена 100svh, фон `ground`.
- По центру рамка 9:16 (на десктопе высота 72svh, radius 28). Над рамкой первая половина фразы Display по центру: **«СТАТИКУ ЛИСТАЮТ»**. Это заголовок h2, обе половины вместе в одном h2.
- Этапы по скроллу (маркеры IntersectionObserver / ScrollTrigger):
  1. В рамке **статичная** афиша (кадр-обложка). Рамка открывается «шторкой» (фирменная шторка из DESIGN.md §8, один раз на сайте).
  2. Афиша **оживает**: кроссфейд в `loop.mp4` той же афиши, загорается красная точка LIVE. Снизу, перекрывая край рамки на 0.3em, приезжает вторая половина фразы: **«ДВИЖЕНИЕ СМОТРЯТ»**.
  3. Рамка увеличивает видео до ×1.8 на детали (дата/лайн-ап), справа от рамки появляется подпись Lead 28ch: «Анимированная афиша останавливает палец в ленте. Оживим ваш макет или сделаем афишу с нуля.» (Сроки не указывать, пока заказчик их не назовёт.)
- **Живая штука (one live thing):** на этапе 1 курсор «Зажми». Зажатие (pointerdown, на телефоне тоже) сразу оживляет афишу, отпускание возвращает статику. Работает пальцем, без скрипта видна статичная афиша.
- Телефон: рамка 70vw, половины фразы по 13vw над и под ней, подпись под фразой.
- Reduced motion: пиннинга нет, статичная и живая версии стоят рядом.

### 4.4 Видео-креативы `#video` (главный продукт №1, продолжение) — чёрное поле
**Композиция:** поле `ink-field` на всю ширину, текст `on-ink`. Слева (колонки 1–6) заголовок Head:
**«АФИШИ, / КОТОРЫЕ ИГРАЮТ»** и абзац Body: «Анимируем афиши, сторис и рекламные ролики для вечеринок, клубов, фестивалей и брендов. Делаем под Instagram, Telegram и экраны в зале.»
Справа и на всю ширину ниже: **Circular Carousel** (21st.dev @nexus-ui, код от заказчика) с 23 видео-креативами.
- Адаптация компонента: вместо `title/description/tag` карточка 9:16 с `poster.webp`. Активная (центральная) карточка играет `loop.mp4` без звука и с точкой LIVE. Подпись на стеклянной плашке `glass-clear`: название события (из имени файла/обложки, например «DJ Meg · 24 мая», «Gothic Carnival», «Batumi · новый сезон»). Тег: «Сторис», «Афиша», «Рекламный ролик».
- Автоплей 3.5 с, пауза при наведении и при открытом лайтбоксе, видимая кнопка «Пауза» (WCAG 2.2.2), стрелки на клавиатуре, свайп на телефоне, точки-индикаторы (активная лаймовая).
- Видео грузятся только у активной карточки и двух соседних, остальные показывают `poster.webp`.
- Клик по активной карточке открывает **VideoLightbox** с `full.mp4` и звуком (цель `video_open`). Листание внутри лайтбокса стрелками и свайпом, закрытие по Esc и свайпу вниз.
- Под каруселью строка-список «Для кого» Lead-размером, через точку: «Диджеи · Клубы и бары · Фестивали · Караоке · Ведущие · Бренды». Под ней кнопка `glass-lime` **«Заказать анимацию ↗»**. На чёрном стекло преломляет карусель.
- Телефон: заголовок сверху, карусель на всю ширину (активная карточка 72vw), кнопка во всю ширину.
- Здесь же, справа от заголовка на десктопе, **мокап iPhone** (`Stylish_iPhone_16_Pr.png` со старого сайта или CSS-рамка) с двумя сторис `video-5` и `video-story-3`, которые сменяют друг друга. Телефон слегка наклонён (−6°) и следует за курсором (±4°).

### 4.5 Афиши и сторис `#posters` (статичные креативы) — белое поле
**Компонент: Tilted Grid Hero** (21st.dev @ruixen.ui, код от заказчика): бесконечный изогнутый поток из 20 статичных афиш (9:16). У краёв поток загибается к зрителю и растворяется.
- Высота блока 90svh на десктопе, 70svh на телефоне. Тайлы 9:16 вместо исходных пропорций компонента.
- Поверх потока (children компонента) по центру: заголовок Head **«АФИШИ / И СТОРИС»** + Body «Статичные афиши, сторис и посты для анонсов. Единый стиль на весь сезон.» Под текстом белая подложка-скрим `ground` 85% с radius 28, чтобы текст читался поверх потока.
- Hover на тайле: поток замедляется до 20%, тайл выходит на 12px вперёд (translateZ). Клик открывает лайтбокс-галерею статичных афиш.
- Reduced motion: поток стоит, горизонтальный скролл пальцем.

### 4.6 Создание сайтов `#sites` (главный продукт №2)
Две части.

**А. «Сайты одним абзацем»** (taste: «Names as one paragraph»):
- Абзац Head-размера на всю ширину (leading 1.05), 6–8 строк: начинается словом **«САЙТЫ:»** в полном `ink`, дальше 17 названий проектов из `content/cases.md` через запятую в `ink-dim`. После каждого названия окно-в-строке 0.8em × 1.2em со скриншотом сайта. Заканчивается точкой. ⚠️ По правилу DESIGN.md «большой абзац ≠ заголовок»: h2 — это только слово «САЙТЫ», остальное `<p>` со ссылками.
- Hover на названии: название становится `ink`, ось wdth 25→45, окошко увеличивается в 1.6 раза. ## 5. Адаптив

- База — 390px. Проверять 390 / 768 / 1024 / 1440 / 1920.
- На телефоне каждый блок собирается по своей схеме из раздела 4 («Телефон: …»).
- Тач-цели не меньше 48×48.
- 3D на телефоне: только первый экран (без прелоадера-капель) и футер. Секция 4.6Б без 3D. Если `navigator.hardwareConcurrency ≤ 4` или `deviceMemory ≤ 4`, 3D футера тоже заменяется фолбэком.
- Видео на телефоне стартуют только во вьюпорте (IntersectionObserver), одновременно играет не больше 2.

## 6. Производительность

| Метрика | Цель (мобильный 4G, Lighthouse) |
|---|---|
| LCP | < 2.5 с (LCP — статичный кадр рыцаря/заголовок, не WebGL) |
| CLS | < 0.05 |
| INP | < 200 мс |
| JS начальный | < 200 КБ gzip без three. Three-часть грузится отдельным чанком после первого кадра |
| Lighthouse Performance | ≥ 85 на мобильном |

- Шрифт: полный вариативный Roboto Flex весит больше 1 МБ. Собрать свой файл через `fonttools`: `varLib.instancer` зафиксировать все оси, кроме `wght` и `wdth` (opsz=144 для заголовков, отдельный статичный файл opsz=14 для текста не нужен, хватит одного), затем `pyftsubset` на кириллицу и латиницу в woff2. Цель ≤ 250 КБ. Preload этого файла, `font-display: swap`, `size-adjust` у системного фолбэка, чтобы не было скачка.
- Картинки AVIF/WebP с `srcset`, видео `preload="none"` + poster, кроме окна-в-строке первого экрана (`preload="metadata"`).
- Канвасы вне экрана ставятся на паузу (`frameloop="demand"` + IntersectionObserver).
